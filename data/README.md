# Data sources
This directory contains yaml files of data sources to ingest into the Rubin_RAG weviate vector database

There is a directory for each specific deployment of the application.

Current directories:
- _base: data sources common to all deployments.
- USDAC: for the Rubin_RAG application deployed at the cloud-based US DAC for use by the Rubin community doing science with Rubin/LSST data products.
- USDF:  for the  Rubin_RAG application deployed at the USDF for internal project use.
